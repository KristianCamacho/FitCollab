# FitCollab

FitCollab es una aplicación web para la gestión colaborativa del entrenamiento y la alimentación entre deportistas, entrenadores, nutricionistas y administradores.

El sistema está desarrollado con:

Frontend: Vue 3 + Vite
Backend: Spring Boot
Base de datos: PostgreSQL
Java: 17
Node.js: 24 o compatible
Gestor de dependencias backend: Maven Wrapper

# Requisitos previos

Antes de ejecutar el proyecto se debe tener instalado:

Java 17
Node.js y npm
PostgreSQL
Git

No es necesario tener Maven instalado globalmente, ya que el proyecto incluye Maven Wrapper.

Para comprobar las instalaciones:

```powershell
java -version
node -v
